# Proyecto TechLab - Laboratorio Semana 4 (APF1)

**Propósito:** Consolidar el desarrollo de una interfaz web coherente, adaptable, interactiva y accesible, integrando Bootstrap y JavaScript.

## Tecnologías y Dependencias
- HTML5 (Semántico)
- CSS3 (Variables, Media Queries, Mobile-first)
- JavaScript (ES6+, Strict Mode)
- **Bootstrap:** Versión 5.3.8 (CSS y JS bundle cargados vía CDN con SRI)
- **Bootstrap Icons:** Versión 1.13.1

## Instrucciones para ejecutar
1. Extraer el contenido de este archivo `.zip` en una carpeta local.
2. Abrir la carpeta raíz `techlab-apf1` en un editor como Visual Studio Code.
3. Iniciar un servidor local (ej. extensión *Live Server*).
4. El proyecto debería abrir automáticamente en el navegador en la ruta `index.html`. No debe haber errores en la consola (DevTools).

## Requisitos Cumplidos
- **RF-01 al RF-05:** Estructura semántica, navbar adaptable, tarjetas y tabla responsive sin desbordes.
- **RF-06 al RF-09:** Modal funcional reutilizable que detecta la tarjeta de origen, validación de formulario nativa interceptada con JavaScript (sin refrescar página), manejo de estados con foco automático y limpieza en cierre.
- **RF-10:** Footer dinámico.
- **Calidad (RC-01 al RC-10):** Se han incluido etiquetas ARIA correctas, contraste focal visible, carga controlada y separación en `css/styles.css` y `js/app.js`.
